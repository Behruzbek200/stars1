  uchun himoya.

1. GITHUB
  Bot tokenini (eski token avval oshkor bo'lgan!), Shop Key va Fragment
  API Key ni kodga YOZMANG. GitHubga faqat bot.py, requirements.txt,
  render.yaml, .gitignore, DEPLOY_UZ.txt yuklang.
  Oldingi mansur_stars_bot repo ichidagi app.py demo botdir. Render yangi
  bot.py ni Start Command orqali ishga tushiradi. Vercelga mos vercel.json
  Renderda ishlatilmaydi.

2. RENDER
  New -> Blueprint (render.yaml) yoki New -> Web Service:
  Build: pip install -r requirements.txt
  Start: python bot.py --render-start
  Paid Starter + Disk (/var/data, kamida 1 GB)
  Python Runtime. Health Check Path: /health

  ENVIRONMENT:
    BOT_TOKEN=BotFather dan olgan YANGI tokeningiz
    OWNER_ID=6232278895  (sizni IDingiz shunday bo'lsagina)
    ENABLE_LIVE_SALES=0   (avval sinov)
    DATA_DIR=/var/data
    DB_FILE=/var/data/stars_shop.sqlite3
    SECRET_FILE=/var/data/stars_shop.secret

  PUBLIC_URL kerak emas: Render RENDER_EXTERNAL_HOSTNAME ni beradi.
  Agar RENDER_EXTERNAL_HOSTNAME bo'lmasa, PUBLIC_URL=https://nom.onrender.com

  Eslatma: Render Free'da SQLite bazasi yo'qoladi; Free Postgres 30 kunda
  tugaydi. Haqiqiy pul uchun pullik disk yoki barqaror DB kerak.
  Agar eski botdagi mijoz balanslari bor bo'lsa, avval DBni va shifrlash
  kalitini zaxiralang. Yangi DB eski balansni o'z-o'zidan ko'chirmaydi.

3. HAMYONAPI.UZ
  https://hamyon-api.uz/ orqali shop_id va shop_key oling.
  HUMO/UZCARD kuzatuv kartasini provayder ko'rsatmalariga muvofiq ulang.
  Telegram bot -> /admin -> 🔌 API va to'lov -> Shop ID / Shop Key.
  complete_url va prepare_url ni admin paneldan nusxalab HamyonAPI
  do'koningizning callback sozlamasiga kiriting.
  HamyonAPI karta va to'lov IDni o'zi beradi; kartani bot kodi
  almashtirmaydi. Provayderning rasmiy muddati 5 daqiqa.

  Callback rasmiy sign: md5(shop_id + payment_id + amount + shop_key).
  To'lov imzosi, provider ID va aniq summa mos kelmasa BALANSGA
  PUL QO'SHILMAYDI. GET status axborot, imzolangan callback asosiy manba.
  Agar provayder callback formati o'zgarsa, qayta moslashtirish zarur.

4. FRAGMENT-API.UZ
  https://fragment-api.uz/ dan loyiha oching, API Key va kerakli
  TON/USDT hamyonini ulang, hamyonni mablag' bilan to'ldiring.
  Bot -> /admin -> 🔌 API va to'lov -> Fragment API Key, USD/UZS.
  Bot -> /admin -> Stars narxlari: 1 ⭐ narxini kiriting.
  Bot -> /admin -> Premium narxlari: 3, 6, 12 oy narxlarini kiriting.
  IP allowlist ishlatilsa, Render outgoing IP chiqishini ruxsat qiling.

5. AVTO TO'LOVNI YOQISH
  1) Avval /admin konfiguratsiyani to'ldiring.
  2) HamyonAPI callback, Fragment /wallet/balance va /getInfo sinovlari
     o'tganini tekshiring.
  3) Render Environment: ENABLE_LIVE_SALES=1; Save & Deploy.
  4) Bot -> /admin -> 🔌 API va to'lov -> Avto to'lovni boshqarish
     -> MAS'ULMAN — YOQISH.
  5) O'Z KARTANGIZDAN kichik haqiqiy balans to'ldiring.
  6) Balance real ko'paydimi, bir to'lov qayta callback qilinsa yana
     ko'paymayaptimi tekshiring.

     haqiqiy delivery muvaffaqiyatli ekanini tasdiqlang.
  8) Premiumni alohida real sinov qiling (3 oy juda qimmat bo'lishi mumkin).
     Bular muvaffaqiyatli bo'lmasdan MİJOZGA TO'LIQ TAYYOR deb bermang.
